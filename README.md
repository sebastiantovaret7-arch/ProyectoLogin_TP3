# Proyecto Login

**Alumno:** Sebastian y Tovar

**Materia:** Análisis de Sistemas

**Año de cursada:** 2026

## Descripción

Proyecto de un sistema de inicio de sesión y
registro de usuarios.

Permite crear cuentas, iniciar sesión y acceder
a un panel de bienvenida.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP 8
- MySQL / MariaDB
- XAMPP

## Instalación

1. Instalar XAMPP.
2. Copiar la carpeta del proyecto en htdocs.
3. Iniciar Apache y MySQL.
4. Abrir phpMyAdmin.
5. Importar el archivo database/proyecto_login.sql.
6. Verificar la conexión en config/conexion.php.
7. Entrar desde el navegador a:

http://localhost/ProyectoLogin_TP3/

## Funcionalidades

- Registro de usuarios.
- Validación de formularios.
- Confirmación de contraseña.
- Inicio de sesión.
- Verificación de usuarios en la base de datos.
- Panel de bienvenida.
- Cierre de sesión.
